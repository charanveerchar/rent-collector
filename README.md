# 🏠 Rent Collector

## 📌 Project Overview

Rent Collector is a simple Python-based expense-sharing application designed for people living in shared flats, hostels, or rooms.

It calculates the total monthly expenses, including room rent, food expenses, and electricity bills, and determines how much each person needs to pay.

## ✨ Features

- Accepts total hostel or flat rent.
- Calculates food and snacking expenses.
- Calculates electricity bills based on units consumed and cost per unit.
- Accepts the number of people sharing the expenses.
- Calculates the total shared expenses.
- Displays the amount payable by each person.

## 🛠️ Technologies Used

- Python 3
- Variables and Data Types
- User Input (`input()`)
- Arithmetic Operators
- Type Conversion (`int()`)
- Basic Mathematical Operations

## ⚙️ How It Works

1. Enter the total room or hostel rent.
2. Enter the total food expenses.
3. Enter electricity units consumed.
4. Enter the electricity charge per unit.
5. Enter the number of people sharing the expenses.
6. The application calculates the total electricity bill.
7. The total expenses are divided equally among all people.

## 💻 Example

**Input:**

```text
Enter your hostel / flat rent = 6000
Enter the amount of food ordered = 2000
Enter the charge per unit = 8
Enter the total of electricity_spend = 100
Enter the number of persons = 4
```

**Output:**

```text
Each person will pay = 2200
```
